# Generated output never introduces a fact

A model builds each Selection by choosing and compressing Accomplishments from the Corpus. It must never invent a fact, a metric, or an outcome that is not already written in a source file — an embellished number on a resume is a liability in the interview that follows. To make this auditable rather than aspirational, every generated bullet carries a reference to the source file it came from, so verification is opening the cited files and comparing, not re-reading the resume with suspicion.

## Consequences

Compression and translation are permitted (they restate existing facts); extrapolation is not. This rule is enforced by review, not by machinery — the source references make checking cheap, but a Selection still ships only after a human has read it.
