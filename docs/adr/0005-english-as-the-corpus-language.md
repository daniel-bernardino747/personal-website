# The Corpus is written in English

Daniel is Brazilian and applies both locally and internationally, so resumes are needed in Portuguese and English. Holding both languages in every Accomplishment was rejected: it doubles the writing effort, and writing is the habit this system most depends on — a perfect bilingual Corpus that stays empty loses to a monolingual one that fills up. English was chosen over Portuguese because the site already reads in English from the same Corpus, technical vocabulary is English in practice, and translating out of English is the safer direction. Portuguese outputs are translated at render time.

## Consequences

Capture happens in the author's second language, which is the main risk to the habit — if it measurably slows capture, reverse this and translate the site instead. Translation restates existing facts and so stays inside [ADR-0003](./0003-no-fabrication-with-source-traceability.md); a translated Selection is still reviewed before it ships.
